개찰알림 위젯 설치

새 알림·오늘 개찰·개찰 대기 숫자와 최근 개찰결과를 아이폰 홈 화면·잠금 화면에서 바로 볼 수 있어요. 15~30분마다 저절로 새로 고쳐지고, 누르면 앱이 열려요.

1. Scriptable 앱 설치 (무료)

앱스토어에서 Scriptable 받기

2. 코드 복사

✓ 앱에 연결된 서버 주소·암호를 코드에 넣어 두었어요.

불러오는 중…

3. Scriptable에 붙여 넣기

  1. Scriptable을 열고 오른쪽 위 + 를 눌러요.
  2. 빈 화면을 길게 눌러 붙여넣기 해요.
  3. 맨 위 이름을 눌러 개찰알림 로 바꾸고 Done 을 눌러요.

4. 홈 화면에 위젯 추가

  1. 홈 화면 빈 곳을 길게 누르고 편집 → 위젯 추가 를 눌러요.
  2. Scriptable 을 찾아 원하는 크기를 골라요.
  3. 추가된 위젯을 길게 눌러 위젯 편집 → Script 에서 개찰알림 를 골라요.

잠금 화면: 잠금 화면을 길게 누르고 사용자화 → 위젯 칸에서 Scriptable 을 추가해요.
