# 나라장터 개찰결과 실시간 알림

관심 사업의 개찰결과가 나라장터 오픈API에 올라오면 **1분 안에** Gmail(선택: 텔레그램)로 알려 줍니다.
알림에는 1순위 업체, 투찰금액·투찰률, 상위 10개 업체 순위, **우리 회사 순위**가 들어갑니다.

서버가 필요 없습니다. 내 구글 계정의 Google Apps Script에서 돌아갑니다.

## 어떻게 감시하나

| 단계 | 주기 | 하는 일 |
|---|---|---|
| 빠른 감시 | 1분 | 방금 **입력된** 개찰결과 전체를 받아 내 조건(공고번호·키워드·기관)에 맞는 것만 골라냄 |
| 안전망 | 30분 | 공고번호·키워드로 직접 다시 조회해서 놓친 건 보충 |
| 알림 | 즉시 | 맞는 건이면 업체별 순위까지 조회해서 메일 발송 (같은 결과는 1번만, 유찰→재입찰처럼 상태가 바뀌면 다시) |

> 오픈API는 나라장터 화면보다 몇 분 늦게 반영될 수 있습니다. "올라온 즉시"보다는 "API에 반영된 뒤 1분 안"입니다.

## 설정 (10분)

### 1. 공공데이터포털 서비스키 발급
1. [data.go.kr](https://www.data.go.kr)에 로그인
2. **「조달청_나라장터 낙찰정보서비스」** 검색 → **활용신청** (보통 바로 승인)
3. 마이페이지 → 개발계정 → **일반 인증키(Decoding)** 복사

### 2. Apps Script 프로젝트 만들기
1. [script.google.com](https://script.google.com) → **새 프로젝트**, 이름을 `개찰알림`으로 변경
2. 기본 `Code.gs` 내용을 모두 지우고 이 저장소의 [`apps-script/Code.gs`](apps-script/Code.gs)를 붙여넣기
3. ⚙️ **프로젝트 설정** → "편집기에 appsscript.json 매니페스트 파일 표시" 체크 → `appsscript.json`을 [`apps-script/appsscript.json`](apps-script/appsscript.json) 내용으로 교체
4. ⚙️ **프로젝트 설정** → 맨 아래 **스크립트 속성** → 속성 추가
   - `G2B_KEY` = 1단계에서 복사한 서비스키

### 3. 감시 조건 고치기
`Code.gs` 맨 위 `CONFIG`만 수정하면 됩니다.

```js
BID_NOS: ['R25BK01250632'],            // 꼭 볼 공고번호
KEYWORDS: ['GIS', '공간정보', '해양'],   // 공고명 키워드
INSTITUTIONS: ['해양수산부'],            // 공고·수요기관
MY_COMPANY_NAME: '올포랜드',             // 순위표에서 강조
```

세 조건 중 **하나만 맞아도** 알림이 옵니다. `EXCLUDE`에 넣은 단어가 공고명에 있으면 제외됩니다.

### 4. 실행 (편집기 위쪽 함수 선택 → ▶ 실행)
1. `testApi`: 처음 실행할 때 권한 승인 창이 뜹니다(**고급 → 개찰알림(으)로 이동 → 허용**). 실행 로그에 최근 개찰결과가 찍히면 키가 정상입니다.
2. `testNotify`: 시험 메일이 오는지 확인합니다.
3. `setup`: **자동 감시를 시작합니다.** (끄려면 `stop`)

특정 공고를 지금 바로 보고 싶으면 `lookup` 함수를 실행하세요(`BID_NOS` 첫 번째 공고 조회).

### 5. 휴대폰 알림
Gmail 앱 알림을 켜 두면 메일이 오는 즉시 푸시가 옵니다. 놓치기 싫으면 Gmail 필터로 제목에 `[개찰완료]`가 들어간 메일에 별표/중요 표시를 붙이세요.

#### (선택) 텔레그램으로도 받기
1. 텔레그램에서 `@BotFather` → `/newbot` → 봇 토큰 받기
2. 만든 봇에게 아무 메시지나 보낸 뒤 `https://api.telegram.org/bot<토큰>/getUpdates`에서 `chat.id` 확인
3. 스크립트 속성에 `TG_TOKEN`, `TG_CHAT_ID` 추가

## 호출 한도
- 기본 설정(평일 08~20시, 1분 간격)이면 하루 약 1,000~1,500회 호출합니다.
- 개발계정 한도(보통 하루 1,000회)를 넘으면 **"[개찰알림 오류] … LIMITED …" 메일**이 옵니다. 이때는 data.go.kr에서 **운영계정 신청**(활용사례 등록, 무료)을 하거나, `TRIGGER_MINUTES: 5`로 바꾸고 `setup`을 다시 실행하세요.
- 키워드가 많을수록 안전망 호출이 늘어납니다(키워드 1개당 하루 약 24회).

## 문제가 생기면
- 오류는 하루 1번 메일로 옵니다. 실행 기록은 Apps Script 왼쪽 **실행** 메뉴에서 볼 수 있습니다.
- `SERVICE_KEY_IS_NOT_REGISTERED_ERROR`: 활용신청 승인 직후에는 키가 반영되는 데 1~2시간 걸릴 수 있습니다.
- 알림이 너무 많으면 `KEYWORDS`를 좁히거나 `EXCLUDE`를 추가하세요.
