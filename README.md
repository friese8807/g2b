# 개찰알림

나라장터에서 사업을 **검색해 감시에 넣어 두면**, 개찰결과가 올라오는 대로 알려 주는 휴대폰 앱이에요.

- **앱 주소**: https://friese8807.github.io/g2b/ (아이폰 Safari로 열고 공유 → 홈 화면에 추가)
- **알림 받는 곳**: 앱(빨간 숫자), Gmail, 텔레그램, 아이폰 위젯. 처음에는 모두 켜져 있어요
- **확인 간격**: 앱 설정 탭에서 1분·5분·10분·15분·30분·1시간 중에 고르면 바로 바뀌어요

| 탭 | 하는 일 |
|---|---|
| 알림 | 받은 개찰결과. 1순위·투찰률·우리 순위가 보이고, 누르면 업체별 순위표가 열려요 |
| 검색 | 사업명이나 기관 이름으로 입찰공고를 찾아요. ★를 누르면 감시에 들어가요. 검색어를 통째로 키워드 감시에 넣을 수도 있어요 |
| 감시 | 감시 중인 공고와 키워드·기관·제외어 |
| 설정 | 확인 간격·시간대, 알림 받을 곳, 우리 회사, 서버 상태·연결 |

> 개찰결과는 공공데이터포털 오픈API로 받아요. 나라장터 화면보다 몇 분 늦게 반영될 수 있어요.

## 처음 설정 (한 번만, 약 15분)

### 1. 공공데이터포털 인증키
1. [data.go.kr](https://www.data.go.kr)에서 아래 **두 가지**를 각각 활용신청해요(보통 바로 승인돼요).
   - 「조달청_나라장터 낙찰정보서비스」: 개찰결과
   - 「조달청_나라장터 입찰공고정보서비스」: 검색
2. 마이페이지 → 개발계정에서 **일반 인증키(Decoding)**를 복사해요.

### 2. 서버(Google Apps Script) 만들기
1. [script.google.com](https://script.google.com) → **새 프로젝트**를 만들고 이름을 `개찰알림`으로 바꿔요.
2. `Code.gs` 내용을 모두 지우고 [`apps-script/Code.gs`](apps-script/Code.gs)를 붙여 넣어요.
3. ⚙️ 프로젝트 설정에서 다음 두 가지를 해요.
   - "appsscript.json 매니페스트 파일 표시"를 켜고, 그 파일을 [`apps-script/appsscript.json`](apps-script/appsscript.json) 내용으로 바꿔요.
   - 맨 아래 **스크립트 속성**에 `G2B_KEY` = 1단계 인증키를 넣어요.
4. **배포 → 새 배포 → 웹 앱**을 골라요. 실행은 **나**, 액세스는 **모든 사용자**로 두고 배포해요(권한 승인: 고급 → 이동 → 허용).
5. 함수 목록에서 **`setup`**을 골라 ▶ 실행해요.
   - 실행 기록에 **앱 연결 링크**, 서버 주소, 연결 암호가 나와요.
   - 데이터는 구글 드라이브의 '개찰알림 데이터' 시트에 저장돼요.
6. `testApi`를 실행해서 두 API가 모두 "정상"인지 확인해요.

### 3. 앱 연결
- **방법 1 (추천)**: 홈 화면에 추가한 앱 → 설정 탭 → 서버 연결 칸에 서버 주소와 연결 암호를 넣어요.
- **방법 2**: 실행 기록의 연결 링크를 Safari로 열면 자동으로 연결돼요. 다만 Safari와 홈 화면 앱은 저장소가 따로라서, 홈 화면 앱에서는 방법 1이 확실해요.

### 4. 텔레그램 (선택)
1. 텔레그램에서 `@BotFather` → `/newbot`으로 봇을 만들고 토큰을 받아요.
2. 스크립트 속성에 `TG_TOKEN` = 토큰을 넣어요.
3. 만든 봇에게 아무 말이나 한 번 보내요. 다음 알림 때 채팅 번호(`TG_CHAT_ID`)를 저절로 찾아 저장해요.
4. 앱 설정 → **시험 알림 보내기**로 확인해요.

### 5. 아이폰 위젯
앱 설정 → 아이폰 위젯 → **설치 안내**를 순서대로 따라 해요(무료 앱 Scriptable 사용).
홈 화면 앱 안에서 열면 서버 주소와 암호가 코드에 자동으로 들어가요.
- 크기: 작은·중간·큰 위젯, 잠금 화면(사각형·원·한 줄)
- 보여 주는 것: 새 알림·오늘 개찰·개찰 대기 숫자, 최근 개찰결과

## 감시는 어떻게 하나

| 단계 | 주기 | 내용 |
|---|---|---|
| 빠른 감시 | 설정한 간격 | 지난 확인 이후 **새로 입력된 개찰결과 전체**를 한 번에 받아, 감시 공고·키워드·기관에 맞는 것만 골라요 |
| 안전망 | 30분 | 개찰 시각이 지난 감시 공고와 키워드로 직접 다시 조회해서 놓친 건을 채워요 |
| 알림 | 바로 | 처음 보는 결과만 보내요. 유찰 → 재입찰처럼 상태가 바뀌면 다시 보내요. 개찰완료면 업체별 순위와 우리 회사 순위까지 붙여요 |

## 호출 한도
- 1분 간격, 평일 8~20시 기준으로 하루 약 1,000회예요. 개발계정 한도(보통 하루 1,000회)에 가까워요.
- 한도를 넘으면 오류 메일이 오고, 앱 설정의 서버 상태에도 표시돼요. 이때는 data.go.kr에서 **운영계정**을 신청하거나(무료) 간격을 5분으로 늘려요.

## 파일

| 파일 | 역할 |
|---|---|
| `index.html` | 앱 화면 전체 (파일 하나) |
| `apps-script/Code.gs`, `appsscript.json` | 서버 (Apps Script에 붙여 넣는 코드) |
| `widget-core.js` | 위젯 본체. 고쳐서 올리면 모든 폰 위젯이 다음 새로고침 때 바뀌어요 |
| `widget-loader.txt`, `widget.html` | Scriptable에 붙여 넣는 코드와 설치 안내 페이지 |
| `manifest.webmanifest`, `sw.js`, `version.txt`, `icon-*` | 홈 화면 설치·새 버전 반영·아이콘 |

- **앱을 고친 뒤**: `version.txt`의 숫자를 올리면 휴대폰에서 다시 열 때 새 버전이 떠요.
- **서버를 고친 뒤**: Apps Script에서 **배포 → 배포 관리 → 수정 → 새 버전**으로 다시 배포해야 반영돼요. 주소는 그대로예요.
